# COST_MODEL — 免费额度成本模型(12 位教师/年级/日)

> 这是**请求量预算**(估算),不是压测成绩,也不是任务并发承诺。
> 账单口径以 Cloudflare Dashboard / 上游平台实际数据为准。

## 假设

- 12 位教师,每人每天 20 轮对话 + 5 张图 → 240 轮对话、60 张图/天
- 图片/原图平均 3MB;缩略图浏览器端生成(0 服务端成本);30 天不删
- 对话轮平均:1 次请求 + 历史/列表刷新 ≈ 3 个动态请求
- 生图:1 次 generate + 每 3–5 秒轮询退避到 10–15 秒 ≈ 6 次轮询 + 1 次 messages + 1 次 versions 刷新

## 每日额度估算表

| 资源 | 估算 | Free 上限 | 占比 |
|---|---|---|---|
| Workers 动态请求 | ≈ 240×3 + 60×9 + 页面/静态外请求 ≈ **1,500–3,000/天** | 100,000/天/账户 | 1.5–3% |
| Worker CPU | 聊天流式转发为主(等待上游不计 CPU);生图 b64 解码是重头,**线上待实测** | 10ms/请求 | ⚠ 关键未知项 |
| D1 读 | 消息/版本/列表 + 审计 ≈ **30–60 万行/天** | 500 万行/天 | 6–12% |
| D1 写 | 消息落库/checkpoint/任务状态 ≈ **2–5 万行/天** | 10 万行/天 | 20–50% |
| R2 存储 | 60 张×3MB×30 天 ≈ **5.4GB/月新增**;约 55 个使用日累计到 10GB | 10 GB-month | 见下 |
| R2 操作 | A 类(写)60+/天;B 类(读)轮询+下载 ≈ 2,000/天 | A 100 万/月,B 1,000 万/月 | <1% |
| Queues | 60 任务 × ~3 ops + 重试 ≈ **200–300 ops/天** | 10,000/天 | 2–3% |
| Cron | 3 个触发器,每 5–15 分钟小批量 | 5 个/账户 | 合规 |

## R2 GB-month 口径说明

免费层是**月均存储量** 10GB-month,不是"达到 10GB 当天即超":
月初清空则月末 5.4GB 也只计 5.4;持续累积跨月才逼近 10。
**建议**:管理员页 `estimated_storage_bytes` 预警线 70%(7GB)/85%/95%;
超线后由管理员**明确操作**归档旧作品,系统默认永不自动删除教师作品。

## 第三方 AI 成本(与 Cloudflare 分账)

| 项 | 单价(示例) | 估算/天 | 估算/月(22 教学日) |
|---|---|---|---|
| 图片 | $0.02/张(站内快照价) | 60 张 = $1.20 | ≈ $26 |
| 对话 | 按上游 token 实际扣费,pending→Cron 核对 | 取决于模型用量 | 以管理页 verified 汇总为准 |

- 站内展示的金额是**估算/核对结果**,不是"实际扣费";两者口径分开,不混算。
- 每年级实例使用独立的 AI 网关密钥,账单天然隔离。

## 阈值与人工核验流程

1. 每月 1 日:负责人按 DEPLOY_GRADE.md 第 7 节记录 Dashboard 实际用量
   (HTTP 请求 / CPU 时长 / D1 rows / Queue ops / R2 GB-month)。
2. 任一项 >70% 月度额度:在本年级管理页查看站内估算定位来源(通常为图片量)。
3. 免费额度真实触达(429/超额报错):记录错误与日期,按 FEASIBILITY.md 备选路线决策,
   **不得静默启用付费服务**。
