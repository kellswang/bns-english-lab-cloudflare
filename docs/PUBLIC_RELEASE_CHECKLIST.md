# 公开仓库发布检查表（发布前必须人工完成）

> 本清单是未来将仓库从 Private 改为 Public 的发布阻断项，不是已经完成的证明。公开操作必须由仓库所有者明确执行；本分支不修改仓库可见性。

## 代码与安全

- [ ] 扫描全部 Git 提交历史和所有分支，不只检查 main 的当前工作区。检索 Token、Cookie、服务密钥、生产数据库 ID、Cloudflare Account ID、教师姓名邮箱、真实教学数据。
- [ ] 如曾经提交过密钥，先到对应服务撤销并轮换；仅从当前文件中删掉并不能清除历史泄漏。
- [ ] 确认 .gitignore 包括所有真实部署配置、CSV、.env、备份、SQL 导出、构建产物、本机凭据文件。
- [ ] 检查 README、测试 fixture、截图、日志、二进制图片/视频、旧分支，确认不会泄漏用户或学校非公开信息。
- [ ] 检查依赖安全公告和已知漏洞，锁定依赖，CI 必须阻止明显的构建与测试失败。
- [ ] 对公众仓库不授予跨年级 Cloudflare 生产账户或部署 Token；每个年级独立保存自己的 Cloudflare Secrets。

## 许可证、内容权利与品牌

- [ ] 明确代码许可证（MIT/Apache-2.0 等），由实际权利人确认后再添加 LICENSE。没有得到授权前，不擅自选择开源许可证。
- [ ] 核查原前端、项目模板、第三方代码、字体、图片、登录动画、媒体文件及教材引用的公开再分发许可。
- [ ] 核查学校名称、徽标、官方标识是否获得公开使用许可；必要时替换成中性演示品牌。
- [ ] 区分公开源代码和允许别人商用、修改、再发布的授权范围。

## 文档与自动部署

- [ ] README 清楚说明实际功能、Cloudflare Free 限制、第三方 AI/邮件成本，以及当前线上验证状态。
- [ ] 从全新 Cloudflare Free 账户实际走完初始化流程，确认 R2 subscription、D1 migrations_dir、Queue/DLQ 与 Secret 注入。
- [ ] 验证 scripts/deploy-grade.mjs 预览不会产生云端变更，正式执行必须带 --apply。
- [ ] 验证已有资源不会被错误复用、覆盖或误删；验证部署失败后的安全人工恢复。
- [ ] 使用模拟教师 CSV 和无生产权限的测试密钥跑完整部署；再用已授权账号验证 Resend 邮件与真实 AI API。
- [ ] 确认用户能先用 workers.dev 域名验收；自定义域名绑定仅作用于自己账户的活动 Zone。
- [ ] 审查成本文档和 Worker/Queue Consumer CPU 在线实测结果；未验收部分保留“未验证”。
- [ ] 编写贡献规范、漏洞报告渠道、版本升级和数据库迁移说明，确认不在公开 Issue 中收集密钥。

## 正式发布

- [ ] 由仓库所有者最后核对公开预览与各个分支历史。
- [ ] 创建明确的稳定版标签并冻结可部署版本。
- [ ] 变更可见性为 Public 前，核对 GitHub 的提示和组织策略，明确操作不可逆的数据传播风险。
- [ ] 公开后监控密钥泄漏告警和 issue；发现风险立即撤销密钥、协调清理。
